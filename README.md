# Work Life Hub

Work Life Hub 是一个纯前端的工作生活管理网站，可以部署到 GitHub Pages。它无需登录，打开即可使用；业务数据保存在用户自己浏览器的 IndexedDB 中，不需要后端服务，也不会上传个人数据。

## 功能

- 首页总览：今日计划、快速备忘录和各模块摘要。
- 今日计划：任务添加、编辑、删除、完成、筛选和优先级管理。
- 快速备忘录：记录临时想法和零散事项。
- 健身计划：记录训练类型、时长和完成情况。
- 饮食计划：记录餐食、饮水和每日备注。
- 游戏娱乐：安排游戏、影视、阅读等休闲计划。
- 自定义项目：创建自己的清单类项目。
- 数据与设置：导出 JSON、导入 JSON、清空本地数据。

## 本地运行

```bash
npm install
npm run dev
```

## 测试

```bash
npm test
```

## 构建

```bash
npm run build
```

构建结果会输出到 `dist/`。

## 部署到 GitHub Pages

1. 将项目推送到 GitHub 仓库。
2. 在仓库设置中启用 Pages。
3. 使用 GitHub Actions 或本地构建，将 `npm run build` 生成的 `dist/` 部署为静态站点。
4. 本项目的 Vite `base` 为 `./`，适合部署到仓库子路径。

## 数据与隐私

本项目没有后端接口，业务数据直接保存在当前浏览器的 IndexedDB 中。不同浏览器、不同设备之间不会自动同步。如需迁移，请在“数据与设置”中导出 JSON，再到新浏览器导入。

注意：本项目第 1 版不做登录或本地密码保护。任何能打开当前浏览器的人，都可以查看本地保存的数据。
